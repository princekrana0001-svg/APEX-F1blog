# APEX - Formula 1 Blogging Website 🏎️

> **Stories. Speed. The World of Formula 1.**

APEX is a frontend-based Formula 1 blogging website developed using **HTML, CSS and JavaScript**.

The website allows users to explore Formula 1 blogs, drivers, teams, technology and history through a clean, responsive and modern interface.

It also includes a **Write a Blog** feature where users can create their own blog by entering basic details and uploading an image. Newly created blogs are displayed dynamically on the Blogs page and are stored using browser Local Storage.

---

## 📌 Project Overview

APEX is designed as a simple and professional Formula 1 blogging platform.

The main purpose of this project is to demonstrate frontend web development concepts such as:

- HTML page structure
- CSS styling and responsive design
- JavaScript DOM manipulation
- Search and filtering
- Dynamic content generation
- Form handling
- Image upload and preview
- Local Storage
- Dark mode
- Responsive navigation

### 📝 Blogs Page

The Blogs page allows users to:

- View all available blogs
- Search blogs by title
- Filter blogs by category
- View the total number of blogs
- Open individual blog articles
- Read blog descriptions
- View blog images
- Create and publish a new blog
